## Ownership

- One main Codex task is the sole same-checkout writer.
- Up to three read-only specialists may inspect independent lanes.
- Specialists are spawned only from a parent turn in live read-only permission mode. Workspace-write main-writer phases run without subagents because the parent runtime can override a custom agent's declared sandbox.
- Every specialist result is collected and reconciled by the main task.
- No independent writer is authorized in Phase A.
- Platform and FFFA apply and validate separately; Platform policy conformance must pass before FFFA adoption applies.
