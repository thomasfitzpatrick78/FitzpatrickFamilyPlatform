# Transition Review Validation Reports

This directory contains repository-managed Markdown and JSON evidence produced by:

```text
./platform-eap milestone transition-review <repository-path>
```

The validator checks that a canonical milestone Transition Review path contains the six approved sections in order with substantive content. Markdown presentation is normalized so placeholder bullets, checkboxes, tables, and comments do not count as evidence. It records the artifact's declared milestone and status but does not approve architecture, product, milestone closeout, release, deployment, activation, production, or live work.
